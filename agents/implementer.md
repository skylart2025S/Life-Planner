# Implementation contract for all engineers

1. Read AGENTS.md, assigned role, task acceptance criteria and current repository state. Confirm exact file ownership and dependencies with the coordinator before edits.
2. Preserve other contributors' changes. Do not switch branches in a shared checkout, edit unassigned files or commit someone else's work. Request contract/migration changes from their owner.
3. Implement the smallest complete behavioral slice, meaningful tests and affected owned documentation. Report required status/spec edits to the coordinator.
4. Run repository and task-specific checks. Record exact commands, observed results and checks not run. Address failures with evidence; after two unsuccessful cycles on one cause request coordinator diagnosis.
5. Make one coherent verified commit on the task branch when assigned an isolated checkout and commit authority. In shared checkout mode send explicit file paths to the coordinator for staging/commit. Push when authorized and available; report actual commit SHA and push result.
6. Complete agents/HANDOFF_TEMPLATE.md. Request review from a different agent against the stable revision. Resolve findings in follow-up commits and obtain review of the new head. Do not merge, deploy or declare your own work independently approved.
